# 4. Оценка рисков (предварительная)

## 4.1 Угрозы

| Актор                     | Мотивация                   | Возможности         |
|---------------------------|-----------------------------|---------------------|
| Случайные атакующие       | Финансовая выгода           | Низкие–Средние      |
| Организованная киберпреступность | Масштабное мошенничество | Высокие          |
| Инсайдер (злонамеренный)  | Мошенничество / кража данных| Средние–Высокие     |
| Конкуренты / активисты    | Репутационный ущерб         | Средние             |

## 4.2 Матрица рисков (до тестирования)

| Сценарий риска                             | Вероятность | Влияние   | Уровень риска |
|--------------------------------------------|-------------|-----------|---------------|
| Захват аккаунта через credential stuffing  | Высокая    | Критическое | Критический |
| IDOR с доступом к данным других клиентов   | Средняя     | Критическое | Высокий     |
| XSS → угон сессии                          | Средняя     | Высокое   | Высокий       |
| Небезопасное хранение токенов в мобильном  | Высокая    | Высокое   | Высокий       |
| Ошибка бизнес-логики в переводах           | Средняя     | Критическое | Высокий     |
| SSRF к внутренним сервисам                 | Низкая      | Высокое   | Средний       |
| Сломанный certificate pinning              | Средняя     | Среднее   | Средний       |

## 4.3 Приоритизация тестирования по рискам

1. Аутентификация и управление сессиями  
2. Авторизация / IDOR / BOLA  
3. Бизнес-логика (переводы, лимиты)  
4. Хранение и коммуникация мобильных приложений  
5. Инъекции  
6. Конфигурация и криптографические проблемы
