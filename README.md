## Обзор

Репозиторий содержит полную **Стратегию тестирования безопасности** и детальный **Тест-план** для гипотетического финансового веб-приложения («FinSecure»), которое включает:

- Адаптивное веб-приложение (десктоп + планшет)
- Нативное iOS-приложение
- Нативное Android-приложение
- Общий REST/GraphQL API backend

Материалы готовы к адаптации под реальные проекты и могут служить шаблоном для тестирования безопасности подобных систем.
